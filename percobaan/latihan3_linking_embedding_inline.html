[Metode Embedding] Internal CSS Aktif

[Metode Linking] Integrasi Arsitektur Tiga Tingkat CSS

Halaman ini mendemonstrasikan bagaimana sebuah dokumen HTML dapat memanfaatkan tiga tingkatan penulisan CSS sekaligus secara harmonis: Linking untuk standarisasi layout global, Embedding untuk pengaturan spesifik halaman, dan Inline untuk sentuhan khusus elemen individual.

[Metode Inline]: Catatan Prioritas CSS

Aturan Inline CSS memiliki tingkat spesifisitas tertinggi dan akan mengesampingkan (override) aturan yang didefinisikan pada Internal maupun External CSS jika terjadi konflik selector.

Implementasi Praktikum Modul 11:
Telah berhasil menghubungkan berkas eksternal.css, menyisipkan blok <style> di bagian <head>, dan menyematkan atribut style="" langsung pada tag HTML.
Metode CSS Lokasi Penulisan Kelebihan Utama
Linking Berkas berekstensi .css terpisah Konsistensi tampilan multi-halaman & hemat bandwidth (caching).
Embedding Tag <style> di dalam <head> Ideal untuk styling eksklusif yang hanya ada pada satu halaman.
Inline Atribut style="" pada tag elemen Sangat cepat untuk pengujian kilat & override lokal spesifik.
